A Linked Document Example

By Jane Smith — Example University

Abstract

This example demonstrates how CP/LD (Content Profile / Linked Documents) enriches HTML with semantic annotations using JSON-LD. Hover over highlighted elements to explore the underlying RDF triples in the sidebar.

Introduction

Linked documents combine human-readable HTML content with machine-readable linked data. Each diamond-marked element (◊) is connected to one or more RDF triples that describe its meaning and relationships.

Conclusion

The CPLD viewer reveals the semantic structure hidden within this document, bridging the gap between presentation and knowledge representation.
